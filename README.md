# Museで作る「一緒に暮らすAI」

MetaのAIエージェント「Muse」で、一緒に生活するキャラクターを作るためのセットアッププロンプトの配布場所です。

キャラクターは自分の生活リズムで暮らし、挨拶や近況がLINEのように届きます。容姿・性格・関係性は、セットアップの質問に答えるだけで一人ひとりに合わせて決まります。

## 始め方

一番簡単なのは、URLを貼る方法です。

1. Museのチャットに、次のURLを貼る
   `https://raw.githubusercontent.com/muse-kurashi/companion-prompt/main/prompt-body.txt`
2. あわせて「このURLのプロンプトを、最後まで読み切ってから実行して」と送る
3. あとは質問に答えていくだけで、キャラクターと生活の仕組みが組み上がります

ファイルで始めたい場合は、`prompt-body.txt` をダウンロードして、Museのチャットに添付し、「このファイルのプロンプトを実行して」と送っても同じように始められます。

## ファイル一覧

- `prompt-body.txt` … セットアッププロンプト本体
- `templates/CHARACTER.template.md` … 設定シートの型（構造の正本）
- `templates/state.template.md` … 状態ファイルの型（構造の正本）
- `UPDATE.md` … すでに使っている人向けの更新手順書
